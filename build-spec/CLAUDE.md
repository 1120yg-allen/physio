## 專案是什麼

一位台灣執業物理治療師(單人營運)的**到宅治療臨床管理系統**。

不是給醫院用的 HIS,不是雲端 SaaS。是一套**本機優先(local-first)、單人可維運**的系統,解決三件事:

1. **自費個案的 SOAP 紀錄**——目標 90 秒完成一筆回診紀錄
2. **長照個案的申報紀錄**——對齊照管系統格式,上傳前先攔錯
3. **排程與個案溝通**——行事曆、LINE 提醒、家屬端進度摘要

使用情境是**到宅服務**:治療師在個案家中或車上操作,可能沒有穩定網路,裝置是 iPhone/iPad。

## 🔴 不可違反的約束(違反即重做)

### C1. 臨床資料不得經由雲端 STT 或雲端 LLM 處理
個案健康資料屬《個人資料保護法》特種個資。語音轉文字、SOAP 結構化,**一律在裝置端或自架環境完成**。

- ✅ iOS 鍵盤內建聽寫(on-device)、本機模型、自架服務
- ❌ 任何第三方雲端語音 API、任何把個案內容送出本機網路的 LLM 呼叫

*例外:完全去識別化、且經使用者明示同意的資料,才可用於模型改良(目前階段不做)。*

### C2. 紀錄保存十年,簽章後鎖定
《物理治療師法》要求治療紀錄保存十年。

- 紀錄一經簽章即**鎖定不可直接覆寫**
- 任何修改必須產生**新版本並保留原版本與修改時間戳**
- 理由:多則地院判決以「業務登載不實」論罪,版本軌跡是自保證據

### C3. 自費與長照是兩條平行軌,不可混淆
| | 自費軌 | 長照軌 |
|---|---|---|
| 紀錄模板 | SOAP | 照管申報格式 |
| 憑證 | 收據(印花稅)/ 運動課程開發票(營業稅) | 由特約單位核銷 |
| 前置 | 治療目的需診斷證明/照會單;非治療目的免醫囑 | 照顧計畫 |
| 匯出 | 不進 FA 申報 | QD110 批次格式 |

**自費紀錄絕對不可混入長照申報資料流。**

### C4. 離線必須可用
到宅現場常無網路。**新增與編輯紀錄、查看個案歷史,離線狀態下必須完整可用**,恢復連線後同步。不得出現「請檢查網路連線」擋住治療師寫紀錄的情況。

### C5. 資料只輸入一次
生命徵象、標準化測驗數值、服務時間戳存在**共用資料層**,兩種模板各自取用。個案在長照與自費之間轉換時,歷史數據不得斷裂。

### C6. 繁體中文
所有 UI 文案、錯誤訊息、文件、程式碼註解一律繁體中文。變數與函式名用英文。

## 技術方向(已定,除非使用者另行指示)

| 面向 | 決定 | 理由 |
|---|---|---|
| 架構 | **Local-first**,資料主體在本機/自家 NAS | C1 法規約束 |
| 前端 | Web App(PWA),可安裝到 iPad 主畫面 | 跨裝置、免上架、離線可用 |
| 離線 | IndexedDB 為本機主儲存 + Service Worker | C4 |
| 後端 | Node 或 Python 輕量服務,跑在使用者自己的 Mac/NAS | 不經第三方雲 |
| 資料庫 | SQLite(單檔,易備份) | 單人規模足夠,備份即複製檔案 |
| 遠端存取 | Tailscale 私有網路(不對公網開放) | 安全且零設定成本 |
| 語音 | 階段一直接用 iOS 鍵盤聽寫(零開發);階段二評估本機模型 | C1 |
| 行事曆 | Google Calendar API(Apple Calendar 無伺服器端 API,以 iPhone 加入 Google 帳號繞過) | 既有調研結論 |
| 訊息 | LINE Official Account Messaging API | 台灣長輩與家屬唯一通用管道 |

**使用者是非工程師、以 AI 輔助開發。** 優先選擇依賴少、設定簡單、單人可維運的方案。避免引入 Docker 叢集、微服務、需要運維的基礎設施。

## 使用者偏好(來自長期協作)

- 偏好**精簡、精確、結構化**的輸出;強烈排斥抽象建議
- 要**可立即執行的交付物**,不要「你可以考慮…」
- 表格能壓縮資訊時用表格
- 規劃階段**一次只問一個問題**
- 文件採**明確版本號**迭代,確認版本後才進下一步
- 他的更正具權威性(例:行政抽成固定 400 元、C 碼按實際次數請領)——遇到與本文件衝突,以他的最新指示為準

## 領域術語表

| 術語 | 意義 |
|---|---|
| **SOAP** | Subjective / Objective / Assessment / Plan,臨床紀錄標準結構 |
| **CA07** | 長照「IADLs/ADLs 復能照護」代碼,給付 4,500 元/組(3 次),**按實際完成次數請領** |
| **CC01** | 長照「居家環境安全或無障礙空間規劃」,給付 2,000 元,含輔具評估報告 1 次措施 1,000 元 |
| **FA100 / FA110 / FA200** | 照管系統申報流程:上傳 / 查詢 / 總表 |
| **FA400** | C 碼非月結個案「提前結案設定」,個案中途結案或移居時的申報前置步驟 |
| **QD110** | 照管系統批次匯入格式 |
| **照管系統** | 政府長照服務管理資訊平台 |
| **報備支援** | 物治師法第 9 條,執業一處為限的例外;跨機構服務須辦理 |
| **照會單 / 診斷證明** | 治療目的之物理治療的法定前置文件 |
| **長照 Level 1/2/3** | 長照人員訓練認證等級 |
| **NPRS** | 疼痛數值評估量表 0–10 |
| **TUG** | Timed Up and Go,起立行走計時測驗 |
| **BBS** | Berg Balance Scale,柏格氏平衡量表 |
| **SPPB** | Short Physical Performance Battery |
| **HEP** | Home Exercise Program,居家運動處方 |
| **委任 vs 僱傭** | 合作治療師採委任契約(非僱傭),影響系統中「申告制」而非「排班制」的設計 |

## 程式碼慣例

- TypeScript 嚴格模式;不使用 `any`
- 日期時間一律存 ISO 8601 + 時區(Asia/Taipei)
- 金額用整數(新台幣元,無小數)
- 所有涉及個案資料的函式,命名與註解需明示其資料敏感性
- 測試:資料層與核銷預檢引擎**必須有單元測試**(這兩處出錯會導致法遵風險)
- Git commit 訊息繁體中文,格式 `類型: 描述`(如 `功能: 新增 SOAP 快速模式`)
