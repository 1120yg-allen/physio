## 怎麼開始

把整個 `build-spec/` 資料夾放進專案根目錄,然後對 Claude Code 說:

```
讀 CLAUDE.md 和 SPEC.md,然後從 TASKS.md 的 P0 開始。
執行前先問我 TASKS.md 最後列的四個問題。
```

---

## 三件最重要的事

1. **臨床資料不得經由雲端 STT/LLM 處理**——個資法特種個資 + 醫療法。整個架構是 local-first 的唯一原因。
2. **紀錄簽章後鎖定、修改留版本軌跡**——多則地院判決以「業務登載不實」論罪,版本軌跡是法庭上的自保證據。
3. **離線必須可用**——到宅現場常無網路,不得出現「請檢查網路連線」擋住寫紀錄。
