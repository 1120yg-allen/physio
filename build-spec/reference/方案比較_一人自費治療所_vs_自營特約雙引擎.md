# 方案比較:一人自費治療所(長照靠他人單位)vs 自營特約雙引擎

*分析日期:2026-10-14|對照基準:產品概念文件 v10.2、三年財務模型(方案 B 場地)*

---

## 零、兩個方案的定義

| | **方案 C(本次評估)** | **方案 A(原計畫)** |
|---|---|---|
| 治療所定位 | 一人治療所,**只接自費**,不申請長照特約 | 自營治療所申請長照特約 |
| 長照案來源 | 以個人身分**報備支援**其他特約單位 | 自己是特約單位,照管中心直接派案 |
| 合作治療師 | 無 | 2–7 位委任合作治療師 |
| 核銷作業 | 由對方單位處理(你不碰 FA 流程) | 自行處理(FA100/110/200 全流程) |
| 平台角色 | 純工具/媒合,無自營案源 | 平台+治療所雙引擎 |

## 一、法規可行性:可行,但有一條紅線要先確認

| 項目 | 狀態 |
|---|---|
| 治療所不申請長照特約 | ✅ 完全可行,無強制要求 |
| 個人報備支援他所執行長照 | ✅ 物治師法第 9 條,執業一處為限但機構間支援不在此限 |
| 同時支援多家單位 | ✅ 可行,但每家都要各別辦理報備 |
| 自費業務 | ✅ 治療目的走診斷證明/照會兩軌,非治療目的免醫囑(第 12 條) |
| **⚠️ 負責人親自主持** | **待確認**——治療所應由負責物理治療師親自主持業務。若多數工時在他所支援、自家治療所長期無業務,衛生局是否有疑義?居家型本就在外服務,相對可辯護,但應於 B1 衛生局電話一併問清楚 |

## 三、關鍵交換:405 元 vs 核銷時間

自營特約每次多拿 405 元,以月 43 次計 = **月多 17,415 元**。
但自營特約要自己跑 FA 核銷、面對三大查核、承擔偽造文書風險。

| 每月核銷投入 | 等值自費案 | 機會成本 |
|---|---:|---:|
| 8 小時 | 4.6 案 | 11,429/月 |
| **16 小時** | **9.1 案** | **22,857/月** |

**若核銷行政每月吃掉 16 小時以上,自營特約的抽成優勢(17,415)就被機會成本(22,857)吃光。**
換句話說:**只有在你能把核銷壓到 8 小時以內、或有足夠合作治療師攤平這筆行政時,自營特約才划算。** 一人規模下,方案 C 在單純財務上並不吃虧。

## 四、方案 C 的真實風險(財務之外)

| 風險 | 嚴重度 | 說明 |
|---|---|---|
| **案源單一依賴沒解決** | 🔴 高 | 這正是整個專案的起點動機。長照收入綁在他人單位的派案意願上,對方抽成可調、自己養人後可減派、合作終止即斷 |
| **收入綁在自己時間** | 🔴 高 | 天花板約 208 萬/年;停診、受傷、生病即歸零,無任何被動收入 |
| **無機構信譽累積** | 🟡 中 | 不是特約單位 → 無法接機構合作、日照、標案(講義 Part 4 的五條通路大多需要特約或單位身分) |
| **自費獲客全自擔** | 🟡 中 | 自費線是方案 C 的命脈,但沒有長照案源當自然轉介池 |
| **報備支援行政分散** | 🟢 低 | 每家單位各辦報備,但一次性成本 |

## 五、對平台計畫的衝擊(這是最需要想清楚的一塊)

### 失去

| 項目 | 影響 |
|---|---|
| 冷啟動引擎 | 「治療師加入第一天就有案接」的承諾消失 → 治療師訂閱價值主張變弱 |
| 核銷模組的自用驗證場域 | 你自己不跑 FA 流程,預檢引擎失去最便宜的需求校準來源(但仍可用他人單位經驗訪談補) |
| 長照派案系統的內部客戶 | 第一個示範客戶沒了,SaaS 要直接賣給陌生單位 |

### 獲得(反轉洞察)

| 項目 | 影響 |
|---|---|
| **中立第三方定位** | 你不是特約單位 = 不跟其他治療所搶案源 → **他們更願意採用你的系統**。當你自己是特約單位時,賣 SaaS 給同業等於請對手裝你的系統 |
| 資源集中 | 不用招募、不用管合作治療師、不用應付查核 → 時間全投自費線與平台開發 |
| 現金流提早轉正 | 第一個月就有盈餘,平台開發可用營運現金支應,不需準備金 |

### 平台路線必須改寫

| | 原路線 | 方案 C 下的路線 |
|---|---|---|
| 治療師端主張 | 有案接 + 工具 | **省時間、省核銷**(純工具價值) |
| 收入線 | 訂閱+抽成+治療所 | SaaS 訂閱 + 自費媒合抽成 |
| 第一批客戶 | 自己的合作治療師 | 台北 20 家特約物治所(見市場分析報告) |

## 六、結論與建議路徑

**方案 C 是「高薪自雇」,方案 A 是「創業」。** 兩者不是好壞之分,是你要什麼的問題:

- 若目標是**穩定高收入、低風險、保有時間自由** → 方案 C 明顯勝出,且第一年就實現
- 若目標是**建立可脫離個人時間的資產** → 方案 A 才做得到,但要承擔兩年回本期與管理複雜度

### 建議:以方案 C 起步,但三個補強不可省

| # | 補強 | 理由 |
|---|---|---|
| 1 | **長照至少報備支援 2–3 家單位** | 不要用新的單一依賴取代舊的單一依賴 |
| 2 | **自費獲客機制優先建立**(個人品牌網站、LINE OA、醫師轉介關係) | 自費是方案 C 的命脈,也是未來升級的本錢 |
| 3 | **保留升級選項** | 治療所隨時可追加申請長照特約,**方案 C → 方案 A 的轉換成本極低**;反之方案 A 的招募與系統投入是沉沒成本。先做 C 等於用低風險買一個 option |

### 升級觸發條件(事先訂好,避免憑感覺)

- 自費量穩定 ≥ 每週 10 案,且候補名單出現 → 代表自費線站穩,可承擔特約的行政負擔
- 或 平台 SaaS 有 ≥ 3 家付費治療所 → 代表平台可獨立成立,治療所特約是加分而非必要
